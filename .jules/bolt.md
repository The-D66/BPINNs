## 2024-05-19 - [TensorFlow and Python Math Optimizations for Neural Network Weights]
**Learning:** `tf.norm(t)**2` computes a square root only to square it back, which wastes compute time. Additionally, Python's `sum()` builds an unbalanced compute graph for tensors compared to `tf.add_n()`. Also, for small shape operations like tensor shapes, `np.prod` has noticeable overhead converting to NumPy types compared to Python's built-in `math.prod`.
**Action:** Replace `sum([tf.norm(t)**2 for t in tensors])` with `tf.add_n([tf.reduce_sum(tf.square(t)) for t in tensors])` which yielded ~3-4x speedups. Replace `sum([np.prod(t.shape) for t in tensors])` with `sum([math.prod(t.shape) for t in tensors])` yielding an ~8x speedup. Always check simple math aggregations in TensorFlow models for these unoptimized patterns.
