## 2026-05-10 - Fast Neural Network Parameter Reductions
**Learning:** In TensorFlow parameter classes (like `Theta` in this PINN codebase), computing the squared sum of all parameters using python's `sum([tf.norm(t)**2 for t in values])` is significantly slower and less numerically stable than `tf.add_n([tf.reduce_sum(tf.square(t)) for t in values])`. Furthermore, calculating the total number of parameters using `sum([np.prod(t.shape) for t in values])` introduces huge unnecessary NumPy overhead compared to Python's built-in `math.prod()`.
**Action:** Always prefer `tf.add_n` over Python `sum` for list of tensors, prefer `tf.reduce_sum(tf.square(x))` over `tf.norm(x)**2` to avoid `sqrt` overhead and `NaN` gradients near zero, and use `math.prod` instead of `np.prod` when dealing with simple tuples like shapes in Python loops to avoid NumPy casting overhead.
