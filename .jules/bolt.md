## 2024-05-19 - [Optimize tf.norm()**2 and np.prod() in custom NN class]
**Learning:** In the custom `Theta` class (`src/networks/Theta.py`) used to manage neural network parameters, calculations for the total parameters size (`size()`) and squared norm sum (`ssum()`) were significantly bottlenecked. `np.prod` is very slow when acting on small objects like `TensorShape`, while Python's `math.prod` is ~10x faster. Additionally, computing squared sums using Python's `sum()` with `tf.norm(t)**2` is extremely slow and has gradient instabilities compared to using native `tf.add_n([tf.reduce_sum(tf.square(t))])`.
**Action:** Always prefer `math.prod` over `np.prod` for small integer tuples or shapes, and use native TensorFlow operations like `tf.add_n` and `tf.reduce_sum(tf.square())` for accumulating tensor norms to avoid graph construction and computational overhead.
