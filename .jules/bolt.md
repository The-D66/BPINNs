## 2024-05-15 - [TensorFlow Graph Optimization]
**Learning:** Using Python's `sum()` on a list of TensorFlow tensors iteratively adds them, generating a deep nested addition operation in the computational graph, which is computationally expensive. Similarly, computing `norm` and then squaring it (`tf.norm(t)**2`) is slower and less numerically stable than computing the square directly (`tf.square(t)`). Finally, `np.prod` on small native Python tuples (like tensor shapes) introduces significant per-call overhead due to converting to/from numpy arrays.
**Action:** Use `tf.add_n([tf.reduce_sum(tf.square(t)) ...])` instead of Python's `sum()` with `tf.norm(t)**2` to efficiently sum squared values of a list of TensorFlow tensors. Use Python's built-in `math.prod` instead of `np.prod` when calculating products of elements in small, simple tuples.
