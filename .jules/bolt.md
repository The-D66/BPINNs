## 2024-05-18 - [Optimization] Accelerating Tensor Aggregations
**Learning:** TensorFlow operations inside list comprehensions combined with Python's built-in `sum()` function lead to measurable overhead, specifically because Python accumulates intermediate eager tensors recursively. In operations like summing the squared norms (`tf.norm(t)**2`) of a sequence, computing the square with `tf.square` and then summing with `tf.add_n` is substantially faster. Additionally, using Python's `math.prod` is remarkably faster than `np.prod` for small operations like computing the number of elements from a tensor's `.shape`.
**Action:** Default to `tf.add_n` when aggregating lists of EagerTensors, instead of `sum()`. Always prefer `math.prod` over `np.prod` for very small scalar reductions like `tensor.shape` or dimensions.
