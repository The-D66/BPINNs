## 2026-05-25 - tf.add_n + tf.reduce_sum(tf.square) is faster than sum + tf.norm()**2
**Learning:** In TensorFlow, computing a squared sum via `sum([tf.norm(t)**2 for t in values])` is highly inefficient because taking the square root (for the norm) and immediately squaring it adds unnecessary computational overhead and potential numerical instability near zero. Using `tf.add_n([tf.reduce_sum(tf.square(t))])` directly is substantially faster (observed ~75% reduction in execution time for this codebase's test suite). Also, `tf.add_n` requires a fallback (like returning `tf.constant(0.0)`) if the input list is empty.
**Action:** When calculating squared sums of a list of tensors in TensorFlow, always prefer `tf.add_n` combined with `tf.reduce_sum(tf.square())` instead of Python's `sum` with `tf.norm()**2`, but be sure to handle empty lists safely.
